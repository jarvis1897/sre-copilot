# Architecture Decision Records

Record each significant decision (for example, a technology choice, a breaking schema change, or an orchestration approach) as a short ADR. Name files `NNNN-kebab-title.md`, numbered in order, and start each one from [0000-template.md](0000-template.md). Don't rewrite an accepted ADR. To change a decision, write a new ADR and mark the old one `Superseded by NNNN`.
